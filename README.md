# 🌌 Projeto Ancoragem: Estrelas e Conhecimento

> **"Sem a noite, não veríamos a luz das estrelas."**

O **Protocolo de Ancoragem** é um framework *open-source* de aquisição poliglota que utiliza a literatura e a astronomia para ensinar múltiplos idiomas simultaneamente. Através da repetição de uma matriz narrativa, o cérebro reduz a carga cognitiva e foca no reconhecimento de padrões etimológicos.

## 📺 Assista ao Lançamento

---

## 🛠 O Método: Hardware + Software

Este projeto trata o aprendizado como um sistema integrado:

* **Software:** O algoritmo de ancoragem contextual e repetição de padrões em línguas irmãs.
* **Hardware:** O livro físico de alta qualidade (papel pólen, foco tátil) projetado para eliminar as distrações digitais.

---

## 📖 A Matriz Narrativa (Base)

A história dos gêmeos serve como o fio condutor para todos os idiomas:

> *"Todas as noites, os gêmeos abrem o livro de astronomia para ver estrelas no céu noturno. O céu escuro da noite é cheio de pequenos pontos de luz..."*

### 🌍 Versão Híbrida (Teste de Integração)

Esta versão mistura os idiomas para testar a retenção profunda do vocabulário:

> "Todas as noites, os **gemini** abrem o **Buch** de astronomia para ver **étoiles** no **cielo** noturno. O **caelum** escuro da **Nacht** é cheio de pequenos pontos de **lumière**. As **stellae** são **luces** antigas, viajando por anos até chegar aos **eyes** deles..."

## 🚀 Como Contribuir

Como um projeto **Open-Source**, este repositório aceita contribuições para expandir a rede de idiomas:

1. **Fork** o projeto.
2. Crie uma nova **Branch** (`git checkout -b feature/novo-idioma`).
3. Adicione a tradução da matriz para um novo idioma (ex: Russo, Grego, Japonês).
4. Abra um **Pull Request**.
